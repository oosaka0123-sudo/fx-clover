# FX-Clover／ポコニカル自動監視システム
## 正式引き継ぎ圧縮完全版 v1.23

更新日：2026-08-18

### 1. 目的と禁止事項

FX-Cloverポコ本人の公式ブログ・公式YouTubeを根拠として、ポコニカルを監視・通知システムへ変換する。

公式情報 → 用語定義 → 出典付きルール → 状態遷移 → Python判定 → バックテスト → リアルタイム監視 → 通知

- 実口座の自動売買は行わない。
- 注文・決済・変更コードは実装しない。
- `orders_enabled: false`を維持する。
- AI分類や研究プロキシを公式ルールへ昇格させない。
- 未来足を候補選択や判定に使用しない。
- 公式未確認事項を推測で埋めない。

### 2. 情報分類

- 【公式ルール】：ポコ本人の公式発言で確認できた内容
- 【設計仕様】：監視システム化のため開発側が定義した内容
- 【研究仕様】：公式未確認だが検証目的で隔離した条件
- 【手動入力】：数値化できない裁量部分
- 【未検証参考情報】：出典なしの一般論や他AI回答。判定へ使用しない

### 3. 対象と時間足

- 現在の正式監視対象：GBPJPY
- ポコニカルは公式にはポンド円ショート特化型として扱う。
- USDJPY・EURJPY・GBPUSDへの展開は研究仕様。現段階の自動監視には混ぜない。

v1.23で取得する5種類の時間足：

- D1（日足）
- H4（4時間足）
- H1（1時間足）
- M15（15分足）
- M5（5分足・執行足）

「5時間足」ではなく「5種類の時間足」。M5を執行足として採用することは、ユーザーの実践経験・本人発言の記憶に基づくユーザー確認事項。ただし正式な一次出典が揃うまでは設計上の採用として管理する。

### 4. 状態機械

【設計仕様】

NO_TRADE → WATCH → READY → SIMULATED_POSITION → NO_TRADE

- STOPは状態ではなく損切り価格属性。
- EXITは終了イベント。
- PARTIAL_TAKE_PROFITは部分決済イベント。
- 残ポジションがある間はSIMULATED_POSITIONを維持。
- 同一足再エントリー禁止は研究仕様／設計上の制限。

### 5. 現在確認できている公式要素

- ポンド円ショート特化
- 上位下降トレンド中の下位戻り売り
- 上位足と下位足が下落方向へ同調する場面
- スラスト後の初戻り売り
- 中段レンジ
- 横横ドン・斜めドン
- 本当の天井や転換トップは狙わない
- フォーメーション完成後では遅いため、右肩になると仮定して入る
- 「エントリーはいつだってWフォーメーションの右肩」
- FRは必須条件ではなく、根拠を増やす要素
- DMA3×3はトレンド、調整局面、トレンド回帰、エントリータイミングに使用
- DMA3×3＝3SMAを3本未来へ表示シフト
- DMA25×5＝25SMAを5本未来へ表示シフト
- 実装式：`DMA3x3[t] = SMA3[t-3]`、`DMA25x5[t] = SMA25[t-5]`

優先確認済み公式記事：

- https://fx-clover.com/?p=7496
- https://fx-clover.com/?p=8616
- https://fx-clover.com/?p=7924

### 6. 公式未確認のまま残す項目

- 中段レンジの開始・終了・数値基準
- 右肩が低い場合の比較対象と数値基準
- DMA25×5の「内側」の厳密な意味
- 障害MAと下方向への伸びしろの数値基準
- H1 WATCHの厳密なAND／OR、有効期間、解除条件
- DMA適用価格
- 十字線の公式扱い
- スイング高値・安値の採用基準
- FE起点・終点、261か261.8か、分割割合
- spread取得時点
- 建値移動、部分決済後のSTOP移動
- XMサーバー時刻の正式変換

これらは自動で固定数値化せず、手動入力または研究仕様として隔離する。

### 7. WATCH仕様

WATCHという状態名と場面A／Bの分類は【設計仕様】。各確認条件は、公式確認済み部分と研究プロキシを分離する。

#### 場面A：上昇局面からの転換監視

- H1 DMA3×3を陰線実体で割り、足が確定した後に監視開始。

#### 場面B：下降トレンド継続中

候補環境：

- 下降BBブレイク
- バンドウォーク
- ブレイク後のコマ足
- ぴよ
- ぴよだまり
- DMA3×3に守られている状態

バンドウォーク型は優先度が高い。ただし厳密なAND／ORは未確定で、単純なフラットAND／ORにしない。上位環境が無効になればWATCH／READYを解除する。

現行のH1 WATCH自動判定は【研究仕様】のプロキシであり、公式ルールそのものではない。

### 8. READY仕様

確認対象：

- 中段レンジ
- 右肩の低いフォーメーション
- DMA25×5内側
- 全レートがDMA3×3の下
- 障害MAと下方向の伸びしろ
- MAパーフェクトオーダー、または進行方向に邪魔なMAがない状態

次の項目はv1.23でも公式数値基準がないため、自動確定しない。

- 中段レンジ
- 右肩の高低
- フォーメーション形状
- DMA25×5内側
- 障害MA
- 伸びしろ

これらは【手動入力】としてレビューする。TRIGGER直前にREADYを再確認することは【設計仕様】。

### 9. TRIGGER仕様

執行足で次を確認する。

- 右肩になると仮定する位置
- 全レートがDMA3×3の下
- DMA3×3を陰線実体で割る
- ローソク足確定を待つ
- 上位足に下落方向で同調したと仮定する
- ショート候補として通知する

始値もDMA3×3の上に必要かは公式未確認。TRIGGERは売買注文ではなく通知イベントである。

### 10. 損切り・決済仕様

#### 損切り

【公式ルール】

- ダブルトップとして扱う場合：左肩高値
- 三尊として扱う場合：中央トップ高値
- spreadを上乗せ

【設計仕様】

`stop_price = stop_anchor_price + spread`

- `stop_anchor_price`は手動入力。
- spread未入力は安全側でTRIGGER拒否。0として黙示処理しない。
- STOP到達時は残数量を全終了するシミュレーション。
- 「ネック高値」を公式ストップとして記載しない。

#### 決済

【公式ルール】

- FEターゲット1・2・3で徐々に軽くする。
- 候補値：127、161.8、261または261.8。

FEアンカー、261か261.8か、分割割合は公式未確定のため手動入力。

DMA_EXIT：DMA3×3を陽線実体で上抜け、ローソク足確定後に残数量を全終了する【設計仕様】。

障害MA接近は本人の裁量例であり、自動決済せず`EARLY_EXIT_ALERT`のみを出す。

### 11. 判定タイミングと研究仕様

確定足で判定：

- WATCHのDMA条件
- READY
- TRIGGER
- DMA_EXIT

価格到達時に判定：

- STOP_LOSS
- FEターゲット

【研究仕様】

- 十字線は陰線・陽線のどちらにも含めない。
- 同一足でSTOPとFEへ到達した場合はSTOP優先。
- 決済足で再エントリーしない。
- AIによるチャート一次分類。
- 直近高値を使う仮ストップ診断。
- MAE・MFE診断。
- 研究診断を公式勝率として扱わない。

### 13. 過去に発見・修正した重要問題

- 手動レビューCSV再読込時のpandas型推論クラッシュ：`dtype=str`指定とCSV往復テストで修正。
- Webhook失敗時に送信済み扱いとなり通知が消失：配信成功後のみACKし、失敗イベントは再試行キューへ残す設計へ修正。
- 初回実行で状態ファイルによりスキップ：状態JSONを配布物から除外し、初回`COMPLETED`を確認。
- 文字列`FALSE`が真として扱われる問題：`_is_true()`で修正。
- レビュー済み候補が最新30件外へ出ると消える問題：レビュー済み行を保持するよう修正。
- spread空欄を0扱いする問題：欠損としてTRIGGER拒否へ修正。
- H1未確定足の未来参照：確定H1足だけを使うリサンプルへ修正・テスト追加。
- READY確定と同一足でTRIGGERする問題：次足以降のみ評価へ修正。
- 旧BATが修正版より古いPythonを起動する配線問題：旧入口を削除し、manifest記載の正式入口へ統一。
- Windows通知：初回WATCH大量通知をベースライン化で防止。成功時ACK・失敗時再送を実装。

未解決の構造的注意：バックテスト基盤とライブ監視は完全同一ロジックではない。研究成績をライブ性能や公式勝率として使用しない。

### 18. 運用上の注意

- Surfaceは電源接続時「カバーを閉じても何もしない」設定済み。
- 電源接続、MT4ログイン、ネット接続を維持する。
- MT4の自動売買はOFFのままでよい。エクスポーターに注文機能はない。
- XMで手動売買しても監視システムはポジションを操作しない。
- チャート上のポジション表示を隠す場合は、TradingView設定→トレーディング→「ポジション」をOFF。ポジション表示右端の×は決済の可能性があるため押さない。
