# FX-Clover 公式一次資料台帳

Issue: #3

この台帳は、ポコニカル自動監視システムが参照する **公式一次資料の索引** です。

## 目的

- ポコ本人の公式ブログ / 公式動画に確認できる内容だけを【公式ルール】候補として扱う
- 【設計仕様】【研究仕様】【手動入力】と混同しない
- AIや第三者解説の推測を本番判定へ昇格させない
- 同じテーマについて年代で説明が変化・拡張している場合、その差を残す

機械可読版: `knowledge/official_sources.json`

---

## 最重要: 年代差を消さない

ポコニカルは公開後も本人によって改良・拡張されているため、古い資料の一文を永久固定ルールとして扱わない。

### 初期資料

`https://fx-clover.com/?p=6913`

- ポンド円
- ショート
- M5 Wトップ右肩

という形で明示されている。

### 後年資料

`https://fx-clover.com/?p=9217`

- EURUSDのポコニカル例
- USDCADのポコニカル例

が本人の公式記事に存在する。

したがって、**「GBPJPYで始まった / 基礎資料ではGBPJPYと明示」** と **「後年もGBPJPYだけに限定されている」** は別の話として扱う。

現在システムがGBPJPYだけを正式監視することは【Project設計仕様】として維持できるが、「ポコニカルそのものが現在もGBPJPY以外では成立しない」とは断定しない。

## 現時点で強く確認できた内容

### 対象通貨・方向

基礎資料 `https://fx-clover.com/?p=6913` では、ポコニカルを **ポンド円 / ショート** として明示している。

後年資料 `https://fx-clover.com/?p=9217` では他通貨でのポコニカル実例が確認できる。

方向については、基礎資料および後年の本人説明から、下降局面・戻り売りを中心とする性格は一貫している。

**システム判断:**

- 正式監視対象 `GBPJPY` → 現状維持【設計仕様】
- 他通貨への展開 → 研究仕様で個別検証してから
- 初期の「GBPJPYのみ」をそのまま現在の普遍ルールへ昇格させない

### 執行足

`https://fx-clover.com/?p=6913`

- M5のWトップ右肩をエントリーとして明示

`https://fx-clover.com/?p=6940`

- 1分と5分の双方を使った公式例が存在

`https://fx-clover.com/?p=8126`

- 後年の教材では、エントリーは5分でも1分でも構わない旨が示されている

**結論:**

- 「M5はポコニカル公式教材で使われる」→【公式確認済み】
- 「ポコニカルはM5でしか入らない」→ 公式根拠なし
- 現行システムの「M5必須」→ 引き続き【設計仕様 / ユーザー確認済み運用要件】

この区別を維持する。

### 環境認識を先に行う

確認資料:

- `https://fx-clover.com/?p=6913`
- `https://fx-clover.com/?p=6940`

下位足のWトップ右肩だけを単独で使うのではなく、上位環境認識を前提としている。

したがって「Wトップ右肩を見つけたら即TRIGGER」のような実装は禁止する。

### 中段レンジ

ここは今回の調査で大きく前進した。

`https://fx-clover.com/?p=7907`

本人は、ポコニカルについて以下の意味関係を明確に説明している。

- 転換のフォーメーションそのものを取りに行く手法ではない
- 調整局面が済んだ後の初動を狙う
- 中段レンジのフォーメーション初動が主戦場
- スラストを待つことで転換初動への飛び乗りを避ける

`https://fx-clover.com/?p=7924`

- 中段レンジのフォーメーションがどこかを教材化
- 中段レンジの初動にも複数タイプがあると説明

**結論:**

「中段レンジとは何を意味するか」という意味論は【公式確認済み】へ前進した。

ただし、プログラムが自動判定するための

- 開始バー
- 終了バー
- 必要本数
- 値幅
- MAとの距離
- レンジ幅

等の固定数値はまだ公式確認できていない。

したがって、意味論は公式ルールとして使えるが、数値判定はまだ研究 / 手動のままにする。

### 右肩

複数の公式教材で、Wトップ / 三尊の右肩をエントリー位置として使用している。

確認資料:

- `https://fx-clover.com/?p=6913`
- `https://fx-clover.com/?p=7389`
- `https://fx-clover.com/?p=8126`
- `https://fx-clover.com/?p=9217`

ただし「右肩が低い」の厳密な比較対象・数値基準はまだ確定できていない。

### FR / Fibonacci

`https://fx-clover.com/?p=6913` では、左肩へFRを逆当てし38.2付近を右肩候補の目安として使う例が説明される。
同記事ではフィボナッチ値を単独の絶対条件として扱わないことも強調されている。

`https://fx-clover.com/?p=7043` では、上位・下位の複数FR重合を使った例がある。

`https://fx-clover.com/?p=9597` の後年資料でも、ポコニカルはFibonacciを使う手法として区別されている。

**結論:** FRは公式要素として扱えるが、38.2を全ケース共通の固定TRIGGER値にしてはならない。

### DMA3-3

確認資料:

- `https://fx-clover.com/?p=7389`
- `https://fx-clover.com/?p=8126`
- `https://fx-clover.com/?p=9551`

DMA3-3は推進波 / 修正波の切替、トレンド回帰、エントリー・決済判断の補助として公式教材内で使われている。

一方で、距離・角度等を勝手に数値閾値化しない。

### MAサンド・障害MA・伸びしろ

`https://fx-clover.com/?p=8283`

- MAサンドを見送り文脈として扱う公式教材がある
- MAが背景として重要であると繰り返し説明される

`https://fx-clover.com/?p=9217`

- 下方向に十分な空間があることを実例の判断材料としている

`https://fx-clover.com/?p=9734`

- MAの角度だけでなく、その先の伸びしろが重要という本人の後年説明がある

**結論:**

障害MA / 伸びしろは「AIが勝手に作った概念」ではなく、本人の公式教材に存在する。

ただし、何pipsなら十分か、ATR何倍なら良いか等の数値は確認できていないため、今は自動固定しない。

### 損切り

公式例では、Wトップ系で左肩をSLアンカーとしている。

確認資料:

- `https://fx-clover.com/?p=6913`
- `https://fx-clover.com/?p=6940`
- `https://fx-clover.com/?p=7043`

現行システムの「左肩高値 + spread」設計と矛盾しない。

### 利確

FEによる分割決済が公式教材で繰り返し使用されている。

確認資料:

- `https://fx-clover.com/?p=6913`
- `https://fx-clover.com/?p=6940`
- `https://fx-clover.com/?p=7043`
- `https://fx-clover.com/?p=8126`

127 / 161.8 / 261.8等は公式例に登場するが、毎回同一のアンカー・割合・ターゲットを強制する根拠はまだ不足している。

## まだ自動確定してはいけない項目

以下は引き続き【手動入力】または【研究仕様】として隔離する。

- 中段レンジの機械判定可能な開始・終了・数値基準
- 右肩の高低の厳密な比較ルール
- DMA25x5「内側」の厳密な意味
- 障害MAまでの必要距離
- 下方向への「伸びしろ」の必要距離
- 全条件の厳密なAND / OR
- FEアンカーの全ケース共通ルール
- 分割決済割合
- 261 / 261.8 の全ケース共通ルール
- DMA適用価格の未確認部分
- XMサーバー時刻変換

## 自動化への反映方針

1. 公式一次資料の事実を台帳へ登録する
2. 同一テーマの複数資料を年代順に比較する
3. 古いルールと後年の拡張を両方残す
4. 公式に一意な条件のみ `official_rule` へ昇格する
5. 数値基準のない裁量語は自動固定しない
6. コード変更前にテストケースへ落とす
7. TRIGGERは通知イベントのまま維持する
8. `orders_enabled: false` を維持する
